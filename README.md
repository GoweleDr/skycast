# SkyCast — Weather Dashboard

A fast, responsive weather dashboard built with **HTML5, CSS3 and vanilla JavaScript**.

**Live demo:** https://goweledr.github.io/skycast/

## Features

- Search any city in the world with live suggestions (keyboard friendly)
- One-click weather for your current location
- Current conditions, feels-like temperature, humidity, wind, UV, pressure and rain chance
- Sunrise/sunset with a sun-position arc
- Scrollable 24-hour outlook and a 7-day forecast with temperature range bars
- Animated backgrounds that change with the weather and time of day (sun, stars, clouds, rain, snow, lightning)
- °C / °F toggle, plus recent searches and preferences saved in your browser
- Fully responsive and respects "reduced motion" settings

## Tech

- HTML5, CSS3 (Grid, Flexbox, glassmorphism, keyframe animations)
- JavaScript (ES6+, Fetch API, async/await, Geolocation API, localStorage)
- [Open-Meteo](https://open-meteo.com/) weather and geocoding APIs (free, no API key)

## Run locally

No build step. Just open `index.html` in your browser, or use the VS Code Live Server extension.
